# 5sim: virtual numbers for SMS verification, for developers and AI agents

**[5sim.net](https://5sim.net)** is a global SMS activation platform, running since 2015. Buy a virtual number for SMS verification from $0.008 and receive SMS online with temporary numbers from 150+ countries for 1,200+ services. You can use it through the website, the [REST API](https://5sim.net/docs) or **MCP for AI agents**.

## 🤖 5sim MCP Server

**[5sim-net/mcp](https://github.com/5sim-net/mcp)** is the official [Model Context Protocol](https://modelcontextprotocol.io) server. With it, Claude, Cursor, Cline, VS Code Copilot, Windsurf and other MCP clients can:

- find the best number for a service, comparing price, stock and delivery rate;
- buy the number and wait for the SMS;
- finish an order, or cancel it for a refund;
- check the balance and history.

```bash
npx -y @5sim-net/mcp
```

It has a server-side price cap, a read-only mode, and tool annotations that make clients ask you before any purchase.
